# Ragini Verma: Portfolio

Plain HTML, CSS and JavaScript. No build step.

## Before you publish
1. Put your resume at `assets/documents/resume.pdf` (the Download button needs it).
2. Add your LinkedIn and GitHub links in `js/script.js` (they stay hidden until filled).
3. Add projects in the `projects` list in `js/script.js`. The Projects section stays hidden until you add one. Put project images in `assets/images/`.

## Update content
Everything (text, education, skills, training, certificates) is in the `profile` object at the top of `js/script.js`.
Colours are at the top of `css/style.css`.

## Publish on GitHub Pages
1. Create a GitHub repository and upload everything in this folder.
2. Go to Settings > Pages.
3. Under Source choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. Your site appears at `https://<your-username>.github.io/<repo-name>/`.
